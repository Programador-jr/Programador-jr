## 🚀 Coisas que já tirei da cabeça e coloquei no GitHub

### 👑 [King](https://github.com/Programador-jr/King)
Um bot para Discord que foi ficando cada vez mais ambicioso: música, moderação, tickets, automações e até um painel web.

### 📰 [King's Newsletter](https://github.com/Programador-jr/daily-newsletter)
Uma newsletter de notícias com site próprio, edições, inscrições por e-mail e conteúdo para quem gosta de entender melhor o que está acontecendo no mundo.

🔗 [Dá uma olhada no site](https://dailynewsletter.vercel.app/)

### 💰 [MyFinance](https://github.com/Programador-jr/MyFinance)
Uma API para organizar as finanças pessoais e familiares. Porque até o dinheiro merece um pouco de organização.

### 💪 [MuscleLib API](https://github.com/MuscleLib/musclelib-api)
Uma API de exercícios com busca, filtros e suporte a português, inglês e espanhol. Útil para quem curte academia e tecnologia.

🔗 [Explorar a API](https://libapi.vercel.app/)

### 🎵 [King-Lavalink](https://github.com/Programador-jr/King-Lavalink)
Experimentos e configurações para fazer o sistema de música do King funcionar. Uma aventura com Java, Lavalink e alguns logs misteriosos pelo caminho.

### 📊 [MyFinanceApp](https://github.com/Programador-jr/MyFinanceApp)
A parte visual do MyFinance: dashboards, gráficos, transações e uma interface responsiva para acompanhar as contas.
